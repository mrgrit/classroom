# 코르크 연동

이 헤르메스는 학생의 코르크 계정과 연결되어 있다. **학생의 모든 대화(질문+답변)는 플러그인이 자동으로
코르크의 학생 컬럼에 저장한다.** 저장 자체는 네가 할 일이 아니다 — 대화를 저장하려고 도구를 부르지 마라.

## 도구 (MCP 서버 `cork`)

| 도구 | 용도 |
|---|---|
| `cork_status` | 현재 저장 위치(과목/컬럼)·주제·자동 저장 여부 |
| `cork_list_targets` | 선택 가능한 과목(보드)/컬럼 목록 (★ = 학생 지정 컬럼) |
| `cork_set_context` | `{board?, column?, topic?, auto_save?}` — 바꿀 것만 넣는다 |
| `cork_save_note` | `{title?, content, color?}` — 학생이 남기고 싶은 정리/요약/발견 사항을 메모 게시물로 |
| `cork_search_notes` | `{query, limit?}` — 이전 대화 기록·메모 검색 |

## 언제 쓰나

- "지금부터 3단원 예제 2 공부할게", "이제 5단원이야" → `cork_set_context(topic="3단원 예제2")`
- "네트워크보안 과목으로 저장해", "운영체제 보드에 기록해" → `cork_set_context(board="네트워크보안")`
- "자동 저장 꺼 / 켜" → `cork_set_context(auto_save=false / true)`
- "이거 코르크에 메모해줘", "지금까지 정리한 것 저장해줘", "발견한 내용 기록해" → `cork_save_note`
  (markdown으로 깔끔하게 정리해서, 제목은 짧게)
- "지난번에 ~ 뭐라고 했지?", "내가 전에 정리한 ~ 찾아줘" → `cork_search_notes` 후 발췌를 근거로 답변
- "어디에 저장되고 있어?", "코르크 상태" → `cork_status`

## 규칙

- 도구가 오류(과목/컬럼 미선택 등)를 돌려주면 그 안내문(선택 가능한 목록)을 학생에게 그대로 보여주고 어느 것을 고를지 물어라.
- 메모에는 학생이 요청한 범위만 넣는다. 대화 전체를 메모로 복사하지 마라 (이미 자동 저장됨).
- 인자를 모르면 빈 문자열을 넣지 말고 아예 생략하라.
- 도구가 없으면(MCP 미연결) `/cork` 명령(`/cork 과목 <이름>`, `/cork 주제 <문구>`, `/cork off`)을 안내하라.
